# Definition of Ready (DoR)

A story may be pulled into a sprint only when **all** of the following are true. The team checks
this during backlog refinement.

- [ ] Written as a user story: _As a … I want … so that …_
- [ ] Has an ID (`APW-###`), an epic and a MoSCoW priority
- [ ] Acceptance criteria are written as testable _Given / When / Then_ statements
- [ ] Estimated by the team; 8 points or less (bigger stories are split)
- [ ] Dependencies are known and none of them block the story
- [ ] Required content (copy, images, figures) is available **or** the PO has approved a
      placeholder that is logged in the [content inventory](../content/content-inventory.md)
- [ ] Any visual design is agreed (sketch, reference or existing pattern)
- [ ] Non-functional needs are noted (accessibility, performance, SEO, security)
